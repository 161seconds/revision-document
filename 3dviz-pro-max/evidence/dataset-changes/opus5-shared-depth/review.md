# Shared geometry, lighting and output review

Reviewed 24 authored records: eight geometry profiles, eight lighting profiles and eight output profiles. The author used Claude Opus 5; independent agent reviews examined the text, selected primary sources, and counterexamples to proposed checks. The author corrected the first review findings; a subsequent review identified seven records with remaining contradictory guidance, corrected before promotion. Final targeted rechecks accepted those corrections.

Corrections include logical mesh topology versus rendering vertices, parameter-domain images, field critical points and contour boundaries, source colour encodings, unlit legend conversion, conditional illumination, validated tessellation scope, and simulation time independent of output frame rate. Existing canonical records were unchanged. Exact hashes identify the promoted new records.

This is editorial and source-scope review, not a renderer or solver result. No scene, export, host installation or visual measurement was executed for these records. Author source-read events preserve the relevant claims and access scope. Independent reviewers could not retrieve some English Blender manual pages that the author had read; moving VTK nightly headers also differed between fetches. These limitations remain explicit and do not establish a failed claim.
