From shift new to shift down

Plain SQL files, five commands.

  1. shift new <name>

    Writes 0046_<name>.up.sql and its .down.sql

  2. shift plan

    Takes --db and --to, like every command

  3. shift check

    Needs a throwaway database in --scratch

  4. shift up --to <n>

    Stops at file <n>, checksums each one

  5. shift down --to <n>

    Reverts newest first, back to <n>

Run shift plan on staging first

Install it, then read what it would do.

$ brew install shift-cli
$ shift plan --db $STAGING_URL
