One sync, every host.

Each host is reached directly over SSH. Nothing sits in the middle.

~ $ burrow add ~/.zshrc ~/.gitconfig ~/.config/nvim
tracking 3 paths
 
~ $ burrow sync desk pi work
desk   ssh   3 files   done
pi     ssh   3 files   done
work   ssh   3 files   done

no server

Three commands.

That is the whole tool.

$ burrow add <path>
Track a file or a folder.
$ burrow sync <host>…
Copy what is tracked to each host, over SSH.
$ burrow status
The last sync, host by host.

What you get to delete.

No server in the middle, so nothing to keep running between syncs.

Install it your way.

Then run burrow add on the first file you miss.

  • Homebrew$ brew install burrow
  • Cargo$ cargo install burrow
  • Script$ curl -fsSL script-url | sh
